## 1. 개요

### 1.1 목적

본 문서는 코브랜드 주간 트래픽 현황 대시보드 시스템의 기술 정책 및 표준을 정의하여, 시스템의 일관성, 보안성, 확장성, 유지보수성을 보장하는 것을 목적으로 합니다.

    ext = os.path.splitext(filename)[1].lower()
    return ext in ALLOWED_EXTENSIONS

# ✅ 권장: 파일 크기 제한

@app.post("/upload")
async def upload_file(file: UploadFile):
    if not validate_file(file.filename):
        raise HTTPException(400, "Invalid file type")

    contents = await file.read()
    if len(contents) > MAX_FILE_SIZE:
        raise HTTPException(400, "File too large")

### 11.4 Windows 실행 스크립트 (start.bat) 패키지 설치 이슈

**문제 상황**:

- `start.bat` 실행 시 매번 `pip install matplotlib pandas openpyxl` 명령이 실행되어 불필요한 시간 지연 발생
- 이미 설치된 패키지도 재검증 과정을 거치며 초기 실행 시간이 30초~1분 이상 소요됨

**원인 분석**:

```batch
# start.bat (Line 9)
start "Backend" cmd /k "call venv\Scripts\activate & pip install matplotlib pandas openpyxl & python server.py"
```

- 패키지 설치 명령이 서버 실행 명령과 함께 매번 실행되도록 설정됨
- 설치 여부 확인 로직 없이 무조건 실행
- 특히 `matplotlib`는 의존성 패키지가 많아 설치/검증 시간이 길어짐

**관련 프로그램 정보**:

| 프로그램   | 용도                     | 평균 설치 시간 | 의존성 수 |
| ---------- | ------------------------ | -------------- | --------- |
| matplotlib | 데이터 시각화 라이브러리 | 15-30초        | 높음      |
| pandas     | 데이터 분석 라이브러리   | 10-20초        | 중간      |
| openpyxl   | 엑셀 파일 처리           | 5-10초         | 낮음      |
| pip        | Python 패키지 관리 도구  | -              | -         |

**권장 해결 방안**:

1. **사전 설치 방식** (권장):

   ```batch
   # 최초 1회만 실행
   venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. **start.bat 개선안**:

   ```batch
   @echo off
   chcp 65001 > nul
   cd /d "%~dp0"

   echo ========================================
   echo [1/2] 백엔드 서버 실행 (8001 포트)
   echo ========================================
   :: 패키지 설치 명령 제거 (사전 설치 권장)
   start "Backend" cmd /k "call venv\Scripts\activate & python server.py"

   echo.
   echo ========================================
   echo [2/2] 프론트엔드 서버 실행 (5173 포트)
   echo ========================================
   cd dashboard
   start "Frontend" cmd /k "npm run dev"

   echo.
   echo 브라우저를 실행합니다...
   timeout /t 4 /nobreak > nul
   start chrome http://localhost:5173
   ```

3. **조건부 설치 방식** (대안):
   ```batch
   :: Python 패키지 설치 여부 확인 후 설치
   python -c "import matplotlib, pandas, openpyxl" 2>nul
   if errorlevel 1 (
       echo 필요한 패키지 설치 중...
       pip install matplotlib pandas openpyxl
   )
   python server.py
   ```

**작업 시간 영향**:

- **현재 방식**: 매 실행마다 30초~1분 지연 (패키지 재검증)
- **개선 방식**: 최초 설치 1-2분, 이후 실행은 즉시 시작 (0초)
- **효율성 향상**: 일일 10회 실행 시 약 5-10분 절약

**정책 권고**:

- ✅ **필수**: 프로젝트 초기 설정 시 `requirements.txt`를 통한 일괄 설치
- ✅ **권장**: `start.bat`에서 패키지 설치 명령 제거
- ⚠️ **주의**: 가상환경(`venv/`) 폴더 삭제 시 재설치 필요
- 📝 **문서화**: 설치 가이드에 사전 패키지 설치 절차 명시

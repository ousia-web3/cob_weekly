#### 4.1.1 server.py

**주요 기능**:

1. **엑셀 파싱**: `parse_excel_data(df)`
2. **TOP 20 추출**: `extract_top20_from_cells(df)`
3. **AI 인사이트 생성**: `generate_ai_insights(df)`
4. **API 엔드포인트**:
   - `POST /analyze`: 엑셀 분석
   - `POST /save-json`: JSON 저장
   - `POST /save-html`: HTML 저장
   - `GET /prompt`: 프롬프트 조회
   - `POST /prompt`: 프롬프트 저장
   - `POST /regenerate-summary`: 요약 재생성

**기술 스택**:

- FastAPI
- pandas, openpyxl
- boto3 (AWS Bedrock)
- python-dotenv

**코드 통계**:

```

API 엔드포인트: 3개
```

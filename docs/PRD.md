# PRD: 코브랜드 주간 트래픽 현황 대시보드

## 1. 프로젝트 개요

**프로젝트명:** 코브랜드 주간 트래픽 현황 대시보드 (신규 UI)
**목표:** 주간 트래픽 보고서 생성을 자동화하는 웹 기반 대시보드 도구를 제작합니다. 사용자가 엑셀/CSV 원본 데이터를 업로드하면, 차트/표로 시각화하고, AI 기반 요약을 생성하며, 최종 보고서를 독립된 HTML 파일로 내보낼 수 있어야 합니다.

## 2. 사용자 흐름 (User Flow)

1.  **접속:** 사용자가 대시보드 생성기 페이지에 접속합니다.
2.  **입력:**
    - 보고서 기간 설정: 연도(2025~2030), 월(1~12), 주차(1~5)를 드롭다운으로 선택합니다.
    - 타이틀 자동 생성: "[2025년 12월 1주차] 코브랜드채널 주요 영역별 UV 레포트 공유" 형태로 자동 조합됩니다.
    - 기간 설정: 연/월/주차 선택 시 "2025.12.29 ~ 2026.01.04" 형태로 자동 계산되며, 텍스트 수정 또는 캘린더 선택으로 변경 가능합니다.
3.  **업로드:** 주간 원본 데이터 파일(Excel/CSV)을 드래그 앤 드롭으로 업로드합니다.
4.  **처리:**
    - 시스템이 파일을 파싱합니다.
    - 지표(전주 대비 증감률, 점유율 등)를 계산합니다.
    - 시스템이 AI(Claude 3.5 Sonnet)를 호출하여 "핵심 요약(Executive Summary)"을 생성합니다.
5.  **미리보기:** 사용자가 데이터와 AI 요약이 채워진 대시보드를 확인합니다.
6.  **내보내기:** "대시보드 생성" 버튼을 클릭하여 보고서를 독립된 HTML 파일로 저장하거나 JSON 데이터로 저장합니다.

## 3. 기능 요구사항

### 3.1 데이터 처리

- **파일 입력:** `.xlsx` 형식 지원 (파일명 예시: `2025_COB_sample.xlsx`).
- **파싱:** Python `openpyxl` 라이브러리 사용 (Backend).
- **데이터 매핑 (Excel 행/열 기준):**
  - **열 범위:** A ~ T (총 20개 열)
  - **행 범위 및 데이터 정의:**
    - **Rows 15 ~ 51:** 메인 대시보드 데이터 (카테고리별 상세 실적).
    - **Rows 84 ~ 93:** TOP 10 리스트 (브랜드몰, 제휴사, 공식인증센터).
    - **Rows 103:** 디바이스 점유율.
    - **Rows 119 ~ 124:** 주간 트래픽 추이.
    - **Rows 128 ~ 133:** 코브랜드 도메인 TOP 20 리스트 (텍스트 영역 추출).
- **스키마:** 위 범위에서 추출한 데이터를 내부 JSON 구조로 변환.
- **지표 계산:** 엑셀에 포함된 계산된 수치(비중, 증감률)를 우선 사용하되, 누락 시 자동 계산.

### 3.2 AI 통합

- **모델:** Anthropic Claude 3.5 Sonnet (AWS Bedrock 경유).
- **리전:** `us-west-2`.
- **워크플로우 (Backend Integration):**
  1. **API 호출:** 프론트엔드에서 엑셀 파일 업로드 시 백엔드 API(`/analyze`) 호출.
  2. **분석 및 생성:** 백엔드에서 데이터 파싱 후 AWS Bedrock을 호출하여 인사이트 생성.
  3. **결과 반환:** 파싱된 데이터와 AI 인사이트를 JSON 형태로 프론트엔드에 반환.
- **기능:** 파싱된 데이터를 기반으로 "핵심 요약(Executive Insight)" 생성.
- **프롬프트:** 요구사항에 정의된 특정 프롬프트 사용 (역할: 데이터 분석가, 작업: 4가지 핵심 인사이트).

### 3.3 대시보드 생성 웹 페이지 UI (Web UI)

- **페이지 구성:** 단일 웹 페이지(SPA) 형태로 제공.
- **상단 컨트롤 패널 (Generator UI):**
  - **타이틀 입력 폼:** 연도/월/주차 선택 드롭다운.
  - **파일 업로드 영역:** "엑셀 파일을 이곳에 드래그 하거나 클릭하여 업로드하세요" 문구와 함께 드래그 앤 드롭 영역 제공.
  - **상태 표시:** 파일 파싱 및 AI 분석 진행률.
- **하단 미리보기 영역 (Preview UI):**
  - 업로드 및 처리가 완료되면 하단에 대시보드 미리보기 렌더링.
  - **레이아웃:** `COB_Weekly UV Dashboard_20251201.html` 기반.
- **구성요소 (미리보기):**
  - **헤더:** 자동 생성된 타이틀 적용.
  - **핵심 요약:** AI 생성 텍스트 (수정/저장 기능 포함).
  - **KPI 카드:** 전체 UV, 모바일 비중, 최고 성장, 최악 감소.
  - **차트:** 주간 추이(영역 차트), 디바이스 점유율(파이 차트), 채널 점유율(파이 차트).
  - **테이블:** 코브랜드 도메인 TOP 20, 카테고리별 상세(토글 기능), 세부 TOP 10 (통합 헤더).

### 3.4 이메일 발송 및 관리 (New)

- **이메일 발송:** 생성된 대시보드 내용을 HTML 이메일로 발송.
- **재발송 기능:** 발송 실패 시 또는 필요 시 이메일 재발송 기능 제공.
- **발송 이력 관리:** 이메일 발송 성공/실패 이력 조회.
- **수신자 관리:** 이메일 수신자 목록 추가/삭제/동기화 기능.
- **메일 본문 작성:** 이메일 상단에 들어갈 인사말 등 본문 텍스트 작성 기능 (선택 사항).
- **템플릿 최적화:** Outlook 등 이메일 클라이언트 호환성을 위한 HTML Table 기반 레이아웃 적용.
- **파일명 규칙:** `email_[Title]_[Timestamp].html` 형식으로 저장.

### 3.5 내보내기

- **JSON 저장:** 파싱/처리된 데이터를 JSON 파일로 저장.
- **대시보드 생성 (HTML):** 데이터와 대시보드 UI가 포함된 독립형 HTML 파일 생성 (공유용).
- **이메일 발송:** 최종 확인 후 이메일 발송.

## 4. 기술 스택

- **프론트엔드:** React 18, Vite, Tailwind CSS, Recharts.
- **백엔드:** Python 3.11+, FastAPI.
- **이메일:** SMTP (Microsoft 365 / Outlook), MIME.
- **라이브러리 (Backend):**
  - `pandas`, `openpyxl`: 엑셀 데이터 처리.
  - `boto3`: AWS Bedrock 연동.
  - `smtplib`, `email`: 이메일 발송.
- **환경:**
  - **Web:** 브라우저 기반 (클라이언트 사이드).
  - **Server:** 로컬 Python 서버 (Port 8001).

1. 프로젝트 개요

엑셀 형태의 주간 트래픽 데이터를 분석하여 시각화된 대시보드를 제공하고, AI 기반의 인사이트가 포함된 HTML 이메일 리포트를 자동 생성 및 발송하는 시스템입니다.

주요 기능

  • 📊 엑셀 데이터 분석: 주간 트래픽 파일 자동 파싱
  • 🤖 AI 인사이트: AWS Bedrock (Claude Sonnet 4.6) 기반 핵심 요약
  • 📈 시각화 대시보드: UV, 증감률, 디바이스 점유율 차트
  • 📧 이메일 리포트: HTML 이메일 자동 생성 및 발송
  • 👥 수신자 관리: 간편한 수신자 목록 관리 및 동기화
  • 📝 프롬프트 관리: AI 프롬프트 직접 수정 및 버전 관리
2 / 10

2. 시스템 요구사항 및 설치

필수 요구사항

  • Python: 3.8 이상
  • Node.js: 16.0 이상
  • AWS 계정: Bedrock 접근 권한
  • SMTP: 이메일 발송 계정

설치 방법

# 1. 백엔드 설정
python -m venv venv
pip install -r requirements.txt

# 2. 프론트엔드 설정
cd dashboard
npm install

4. 사용 방법 - 엑셀 업로드

  1. 기간 설정: 상단 드롭다운에서 연도/월/주차 선택
  2. 파일 업로드:
    • 중앙 영역에 엑셀 파일 드래그 앤 드롭
    • 또는 클릭하여 파일 선택
  3. 분석 시작:
    • "분석 시작" 버튼 클릭
    • 진행률 바(Progress Bar) 확인

5. 대시보드 미리보기 UI

📊 핵심 지표 & 차트

  • KPI 카드: 전체 UV, 증감률, Best/Worst 카테고리

  • Top 20 리스트: 주요 대리점 성과 순위 (신규진입 표시)

    (토글 버튼으로 펼치기/접기 가능)
  • 유형별 Top 10: 브랜드몰/제휴사/인증센터 순위

6. 사용 방법 - 요약 및 본문 작성

🤖 AI 핵심 요약 검수

  • 자동 생성: 데이터 기반 4가지 인사이트
  • 요약 재생성: 마음에 들지 않을 경우 즉시 재생성

📝 프롬프트 관리

  • 프롬프트 수정: "프롬프트 관리" 버튼 클릭
  • 실시간 반영: 수정 후 저장 시 즉시 적용

✍️ 메일 본문 작성

  • 기능 활성화: "메일 본문 추가" 체크
  • 에디터 사용: 인사말, 공지사항 작성
  • 서식 적용: 굵게, 색상 등 스타일 적용

7. 사용 방법 - 수신자 및 발송

👥 수신자 관리

  • 추가/삭제: 팝업에서 간편하게 관리
  • .env 동기화: 목록 영구 저장

📧 이메일 발송

  • 우측 상단 "이메일 발송" 버튼 클릭
  • 발송 완료 알림 확인

📜 발송 이력 및 재발송

  • 하단 "발송 이력" 섹션
  • 성공/실패 상태 확인
  • "보기": 발송된 원본 HTML 확인
  • "재발송": 즉시 재전송 (제목에 [재발송] 태그)

8. 프로젝트 구조

cob_weekly/

├── server.py           # FastAPI 백엔드
├── email_service.py    # 이메일 모듈
└── start.bat           # 실행 스크립트

9. 트러블슈팅

이메일 발송 실패 시

.env 파일의 SMTP 설정을 확인하고, 사내 보안 정책으로 인한 포트 차단 여부를 점검하세요.

AI 인사이트 생성 실패 시

AWS 자격 증명(Credentials)이 올바른지, Bedrock 접근 권한이 있는지 확인하세요.

서버 연결 오류 시

start.bat을 통해 백엔드(8001)와 프론트엔드(5173)가 모두 정상 실행되었는지 확인하세요.

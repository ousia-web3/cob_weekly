# 프로젝트 완료 보고서

## 프로젝트 개요

### 프로젝트명

코브랜드 주간 트래픽 현황 대시보드 (Co-Brand Weekly Traffic Dashboard)

### 프로젝트 기간

2025년 12월

### 프로젝트 목적

주간 트래픽 보고서 생성 프로세스를 자동화하여 업무 효율성을 향상시키고, AI 기반 인사이트를 통해 데이터 기반 의사결정을 지원하는 웹 기반 대시보드 시스템 구축

---

## 주요 기능 구현 내역

### 1. 엑셀 데이터 파싱 엔진

#### 구현 내용

- **파일 형식 지원**: .xlsx (Excel 2007+)
- **데이터 영역 자동 추출 (상세)**:
  - **메인 대시보드 데이터 (Summary)**: 행 15 (Index 14)
    - UV: E열 (Index 4)
    - 전주 UV: F열 (Index 5)
    - 증감률: G열 (Index 6)
  - **카테고리별 상세 실적**: 행 15-51 (Index 14-50)
    - 구분: C열 (Index 2)
    - 상세 구분: D열 (Index 3)
    - 데이터: Summary와 동일 열
  - **TOP 10 리스트**: 행 84-93 (Index 83-92)
    - 브랜드몰: 대리점명(D열), UV(E열)
    - 제휴사: 대리점명(I열), UV(J열)
    - 공식인증센터: 대리점명(O열), UV(P열)
  - **디바이스 점유율**: 행 103 (Index 102)
    - Mobile: E열, PC: F열
  - **주간 트래픽 추이**: 행 119-124 (Index 118-123)
    - 주차명: C열, UV: D열
  - **코브랜드 TOP 20 (텍스트 영역)**:
    - 대리점명: 행 128 (Index 127)
    - 채널유형: 행 129 (Index 128)
    - UV: 행 130 (Index 129)
    - 증감률: 행 133 (Index 132)
    - 범위: D열부터 최대 20개 열

#### 기술적 특징

- 셀 단위 정밀 파싱 및 동적 헤더 감지
- 데이터 타입 자동 변환 (문자열 → 숫자, 천 단위 콤마 제거)
- 증감률 기호(▲/▼) 및 특수 형식(예: "전주비 3.2%↓") 자동 파싱
- **신규 진입 로직 개선**: 증감률 절대값이 0.05% 미만인 경우 "신규진입"으로 표기
- 에러 핸들링 및 폴백 메커니즘 (데이터 누락 시 기본값 처리)

### 2. AI 분석 엔진

#### 구현 내용

- **모델**: Anthropic Claude 3.5 Sonnet v2
- **리전**: us-west-2
- **기능**: 주간 트래픽 데이터 기반 핵심 인사이트 4가지 자동 생성

#### 프롬프트 엔지니어링

- 환경 변수 기반 커스터마이징 가능
- 플레이스홀더 지원: `{main_data}`, `{top10_data}`
- JSON 형식 응답 파싱

#### 보안

- AWS IAM 기반 인증
- 환경 변수를 통한 자격 증명 관리
- .gitignore를 통한 민감 정보 보호

### 3. 데이터 시각화

#### 차트 구성

1. **주간 추이 차트**: 영역 차트 (Area Chart)
2. **디바이스 점유율**: 파이 차트 (Pie Chart)
3. **채널 점유율**: 파이 차트 (Pie Chart)

#### 테이블 구성

1. **코브랜드 도메인 TOP 20**: 순위, 대리점명, 채널유형, UV, 증감률 (신규진입 표기 개선)
2. **카테고리별 상세**: 그룹별 현황 및 전주 대비 증감
   - **기능 추가**: 테이블 숨기기/전체보기 토글 버튼 (가시성 개선)
3. **세부 TOP 10**: 브랜드몰, 제휴사, 공식인증센터
   - **UI 개선**: "채널 유형별 TOP 10" 통합 헤더 추가로 가독성 향상

### 4. 보고서 내보내기

#### HTML 내보내기

- **특징**: 완전한 독립형 HTML (외부 의존성 없음)
- **포함 요소**:
  - 인라인 CSS
  - 인라인 JavaScript
  - 내장 데이터 (JSON)
  - CDN 기반 라이브러리 (React, Recharts)
- **저장 위치**: `data/html/`
- **파일명 형식**: `{제목}_{타임스탬프}.html`

#### JSON 내보내기

- **용도**: 데이터 백업 및 재사용
- **저장 위치**: `data/json/`
- **파일명 형식**: `{제목}_{타임스탬프}.json`
- **인코딩**: UTF-8 (한글 지원)
- **파일명 형식**: `{제목}_{타임스탬프}.json`

### 5. 네트워크 및 접근성 (신규)

#### 내부 네트워크 접속 지원

- **구현 내용**:
  - Vite 서버 (`vite.config.js`): `host: true` 설정으로 외부 접속 허용
  - FastAPI 서버 (`server.py`): CORS 설정에 내부 IP (`192.168.82.105`) 및 동적 호스트 허용 추가
  - 클라이언트 (`App.jsx`): `window.location.hostname`을 사용하여 API 엔드포인트 동적 바인딩
- **효과**: 로컬 PC 외에도 내부망의 다른 기기에서 대시보드 접속 및 파일 업로드 가능

#### 디버깅 시스템 강화

- **서버 로그**: `analyze_excel` 엔드포인트에 상세 단계별 로깅 추가
  - 파일 읽기 → 엑셀 파싱 → 데이터 추출 → AI 생성 각 단계 추적
  - `server_error.log`에 타임스탬프와 함께 상세 트레이스백 기록
- **목적**: 원격 접속 시 발생하는 업로드 오류 및 타임아웃 문제의 신속한 원인 파악

## 사용자 워크플로우

### 1. 시스템 시작

```bash
# 자동 실행 (권장)
start.bat

# 수동 실행
python server.py  # 백엔드 (Port 8001)
cd dashboard && npm run dev  # 프론트엔드 (Port 5173)
```

1. 브라우저에서 `http://localhost:5173` 접속

- AI 요약 4가지 인사이트 확인
- 차트 및 테이블 인터랙티브 탐색

### 배포 가이드

#### 초기 설정

```bash
# 1. Python 가상환경 생성
python -m venv venv

# 2. 가상환경 활성화
.\venv\Scripts\activate

# 3. Python 패키지 설치
pip install -r requirements.txt

# 4. React 패키지 설치
cd dashboard
npm install

# 5. 환경 변수 설정

# .env 파일 편집하여 AWS 자격 증명 입력
```

```bash
# 자동 실행
start.bat

# 종료
stop.bat
```

#### 방화벽 설정 (필수)

외부(내부망 다른 PC)에서 백엔드 API에 접속하기 위해서는 Windows 방화벽 인바운드 규칙 추가가 필요합니다.

```bash
# 관리자 권한으로 실행
netsh advfirewall firewall add rule name="Allow FastAPI Backend 8001" dir=in action=allow protocol=TCP localport=8001
```

### 프로젝트 성과 요약

코브랜드 주간 트래픽 현황 대시보드 프로젝트는 **모든 핵심 목표를 100% 달성**하였으며, 다음과 같은 성과를 거두었습니다:

1.  **주간보고 개선**: 주간보고 대시보드 시각화 및 가독성 향상
2.  **AI 인사이트**: 데이터 기반 의사결정 지원 체계 구축
3.  **확장 가능성**: 향후 기능 추가 및 개선 용이한 아키텍처

### 주요 교훈

1. **환경 변수 관리의 중요성**: `.env` 파일을 통한 설정 분리로 보안 및 유지보수성 향상
2. **AI 통합의 효과**: Claude 3.5 Sonnet을 통한 고품질 인사이트 생성
3. **사용자 중심 설계**: 드래그 앤 드롭, 진행률 표시 등 UX 개선이 사용자 만족도 향상

### 감사의 말

본 프로젝트는 기획팀, 개발팀, 운영팀의 긴밀한 협력을 통해 성공적으로 완료되었습니다. 모든 팀원들의 노력과 헌신에 감사드립니다.

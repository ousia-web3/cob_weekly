# 엑셀 파일 업로드 에러 수정 보고서

## 1. 문제 상황

- **증상**: 엑셀 파일 드래그 업로드 시 `Server Error: Internal Server Error` 발생
- **원인**: 업로드된 엑셀 파일의 행 개수가 예상보다 적어, 특정 행(증감률 데이터, 행 133/인덱스 132)에 접근할 때 `IndexError`가 발생함.
  - 에러 로그: `IndexError: index 132 is out of bounds for axis 0 with size 131`
  - 파일의 실제 행 수: 131개 (인덱스 0~130)
  - 접근 시도 인덱스: 132

## 2. 해결 방법

- **수정 파일**: `server.py`
- **수정 내용**: `extract_top20_from_cells` 함수 내에서 증감률 데이터에 접근하기 전에 행 인덱스가 유효한지 확인하는 로직 추가.
  - `growth_row`가 전체 데이터프레임의 행 개수보다 작은 경우에만 데이터에 접근하도록 수정.
  - 범위를 벗어나는 경우 증감률(`growth`)을 0으로 처리하여 에러 방지.

## 3. 결과

- 행 개수가 부족한 엑셀 파일 업로드 시에도 서버가 중단되지 않고 정상적으로 데이터를 처리할 수 있게 됨.

## 4. 향후 계획

- 엑셀 템플릿 변경에 유연하게 대응할 수 있도록, 고정 인덱스 대신 키워드 검색 등을 통한 동적 인덱싱 도입 고려 필요.

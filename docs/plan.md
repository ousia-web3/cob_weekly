# 문서 업데이트 및 정리 계획

## 1. 개요

현재 프로젝트의 최신 상태(이메일 발송/재발송 기능, 에디터 기능 등 포함)를 반영하여 `docs` 폴더 내의 모든 마크다운 파일을 업데이트하고, 불필요하거나 중복된 파일들을 삭제하여 문서화를 체계화합니다.

## 2. 파일 삭제 (불필요한 파일 정리)

다음 파일들은 임시 파일, 중복 정보, 또는 더 이상 관리되지 않는 파일로 판단되어 삭제합니다.

- **임시/작업 내역 파일**: `task.md`, `재발송기능_작업내역.md`, `코브랜드주간현황작업.md`, `bugfix_excel_upload.md`
- **중복/생성된 파일**: `manual.html`, `sample_manual.html`, `package_installation.md` (매뉴얼/README에 통합됨)
- **기타**: `2025_COB_sample.xlsx` (문서 폴더 부적합), `dashboard_data_schema.json` (기술 문서에 통합)

## 3. 문서 업데이트 계획

### 3.1 `PRD.md` (제품 요구사항 정의서)

- **이메일 서비스 기능 구체화**: '이메일 발송 및 관리' 섹션을 '구현 완료' 상태로 업데이트하고, 수신자 관리, 발송 이력, 재발송, 본문 에디터 기능을 상세히 기술합니다.
- **최신 기능 반영**: 프로젝트 진행 중 추가된 UI/UX 개선 사항(드래그 앤 드롭, 진행률 표시 등)을 반영합니다.

### 3.2 `기술정책정의서.md`

- **API 엔드포인트 현행화**: `server.py`의 실제 구현 내용에 맞춰 API 목록을 업데이트합니다.
  - 추가: `/api/recipients` (GET, POST, DELETE), `/api/email/history`, `/api/email/resend/{history_id}`
- **프론트엔드 컴포넌트 현행화**: `EmailBodyEditor`, `EmailHistory`, `GeneratorControls` 등 실제 구현된 컴포넌트 구조를 반영합니다.

### 3.3 `프로젝트_매뉴얼.md`

- **사용자 가이드 보강**:
  - **이메일 본문 에디터**: Quill 에디터를 사용한 인사말 작성 방법 추가.
  - **재발송 기능**: 발송 이력 확인 및 재발송 절차 상세 안내.
  - **수신자 관리**: 수신자 추가/삭제 및 .env 동기화 기능 설명.

### 3.4 `산출물.md`

- **목록 최신화**: 삭제된 파일들을 목록에서 제거하고, 업데이트된 문서 및 코드 구조를 반영합니다.
- **통계 업데이트**: 현재 코드 라인 수 및 파일 현황을 대략적으로 업데이트합니다.

### 3.5 `프로젝트_완료_보고서.md`

- **구현 내역 업데이트**: 이메일 서비스 및 에디터 기능 구현을 '주요 기능 구현 내역'에 추가합니다.
- **시스템 현황 반영**: 현재 시스템 아키텍처와 일치하도록 내용을 조정합니다.

## 4. 실행 순서

1. 불필요한 파일 삭제
2. `PRD.md` 업데이트
3. `기술정책정의서.md` 업데이트
4. `프로젝트_매뉴얼.md` 업데이트
5. `프로젝트_완료_보고서.md` 업데이트
6. `산출물.md` 업데이트

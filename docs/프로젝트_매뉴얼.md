# 코브랜드 주간 현황 리포트 생성기 (Co-Brand Weekly Report Generator) 매뉴얼

## 1. 프로젝트 개요

본 프로젝트는 엑셀 형태의 주간 트래픽 데이터를 분석하여 시각화된 대시보드를 제공하고, AI 기반의 인사이트가 포함된 HTML 이메일 리포트를 자동 생성 및 발송하는 시스템입니다.

### 주요 기능

- **엑셀 데이터 분석**: 주간 트래픽 엑셀 파일을 업로드하여 자동 파싱 및 분석
- **AI 인사이트 생성**: AWS Bedrock을 활용하여 데이터 기반의 핵심 요약 자동 생성
- **대시보드 시각화**: 주요 지표(UV, 증감률, 디바이스 점유율 등)를 차트와 테이블로 시각화
- **이메일 리포트 생성 및 발송**: 분석된 데이터를 바탕으로 HTML 이메일 리포트 생성 및 SMTP 발송
- **수신자 관리**: 이메일 수신자 목록 관리 (추가/삭제/동기화)
- **발송 이력 및 재발송**: 과거 발송된 이메일 이력 조회 및 재발송 기능

---

## 2. 시스템 요구사항 및 설치

### 필수 요구사항

- **Python**: 3.8 이상
- **Node.js**: 16.0 이상
- **AWS 계정**: Bedrock 접근 권한 필요 (AI 기능 사용 시)
- **SMTP 서버 정보**: 이메일 발송을 위한 SMTP 계정

### 설치 방법

#### 1. 백엔드 (Python) 설정

프로젝트 루트 디렉토리에서 실행합니다.

```bash
# 가상환경 생성 (선택사항)
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 의존성 패키지 설치
pip install -r requirements.txt
```

#### 2. 프론트엔드 (React) 설정

`dashboard` 디렉토리로 이동하여 실행합니다.

```bash
cd dashboard
npm install
```

#### 3. 환경 변수 설정 (.env)

프로젝트 루트에 `.env` 파일을 생성하고 다음 정보를 입력합니다. (예시: `.env.example` 참조)

```ini
# AWS Bedrock 설정 (AI 인사이트용)
AWS_REGION=us-west-2
MODEL_ID=anthropic.claude-3-5-sonnet-20241022-v2:0
ANTHROPIC_VERSION=bedrock-2023-05-31

# 이메일 SMTP 설정
SMTP_SERVER=smtp.example.com
SMTP_PORT=587
EMAIL_SENDER=your-email@example.com
EMAIL_PASSWORD=your-password
EMAIL_RECIPIENTS=receiver1@example.com,receiver2@example.com
```

## 3. 접속 및 실행 가이드

### 3.1 서버 실행 (관리자)

1. 프로젝트 폴더의 `start.bat` 파일을 실행합니다.
2. 서버가 정상적으로 실행되면 크롬 브라우저가 자동으로 열립니다.

### 3.2 접속 주소

#### 관리자 (서버 실행 PC)

- 주소: `http://localhost:5173`

#### 내부 임직원 (사내망 접속)

- 주소: `http://192.168.82.105:5173`
- **참고**: 사내망의 다른 PC나 모바일 기기에서도 위 주소로 접속하여 대시보드를 확인하고 파일을 업로드할 수 있습니다. (단, 서버 PC의 방화벽 설정에서 8001, 5173 포트 허용 필요)

## 4. 상세 사용 방법 (화면 기능 가이드)

### 4.1 엑셀 파일 업로드 및 분석

1. **기간 설정**: 화면 상단의 드롭다운 메뉴에서 보고서의 **연도, 월, 주차**를 선택합니다. (날짜 범위는 자동으로 계산되어 표시됩니다.)
2. **파일 선택**:
   - 중앙의 **"엑셀 파일을 이곳에 드래그..."** 영역에 파일을 끌어다 놓거나,
   - 영역을 클릭하여 파일 탐색기에서 분석할 엑셀 파일을 선택합니다.
3. **분석 시작**: 파일이 선택되면 **"분석 시작"** 버튼이 활성화됩니다. 클릭하면 분석이 시작됩니다.
   - **진행률**: 분석 단계(파일 읽기 -> 데이터 파싱 -> AI 분석)에 따라 진행률 바가 표시됩니다.

### 4.2 AI 핵심 요약 검수 및 수정

분석이 완료되면 대시보드 상단에 AI가 생성한 **"핵심 요약(Executive Summary)"**이 표시됩니다.

- **내용 확인**: AI가 데이터에 기반하여 작성한 4가지 주요 인사이트를 확인합니다.
- **직접 수정**:
  - 각 요약 항목의 텍스트 박스를 클릭하여 내용을 직접 수정할 수 있습니다.
  - 오타 수정이나 강조하고 싶은 내용을 추가하세요. 수정된 내용은 이메일 발송 시 그대로 반영됩니다.

### 4.3 메일 본문 작성 (에디터 기능)

이메일 상단에 들어갈 인사말이나 공지사항을 작성합니다.

1. **기능 활성화**: 대시보드 우측 상단의 **"메일 본문 추가"** 체크박스를 클릭합니다.
2. **에디터 사용**: 나타나는 에디터 창에 내용을 작성합니다.
   - **서식 적용**: 텍스트를 드래그하고 굵게(Bold), 밑줄, 색상 변경 등을 적용할 수 있습니다.
   - **내용 예시**: "안녕하세요, 금주 코브랜드 트래픽 현황 공유드립니다. 특이사항으로는..."

### 4.4 수신자 관리

이메일을 받을 대상자를 관리합니다.

1. **관리 팝업 열기**: 우측 상단의 **"수신자 관리"** 버튼을 클릭합니다.
2. **수신자 추가**: 입력창에 이메일 주소를 입력하고 **"추가"** 버튼을 누릅니다.
3. **수신자 삭제**: 목록에서 삭제할 이메일 옆의 **"삭제(휴지통)"** 아이콘을 클릭합니다.
4. **동기화**:
   - **".env 동기화"**: 현재 목록을 환경 설정 파일에 영구 저장합니다.
   - **"초기화"**: 환경 설정 파일에 저장된 목록으로 되돌립니다.

### 4.5 이메일 발송 및 이력 관리

1. **발송하기**: 모든 확인이 끝나면 우측 상단의 **"이메일 발송"** 버튼을 클릭합니다.
   - 발송 성공 시 "발송 완료" 알림이 뜹니다.
2. **발송 이력 확인**: 화면 최하단의 **"발송 이력"** 섹션에서 내역을 확인합니다.
   - **상태**: 성공/실패 여부가 표시됩니다.
   - **미리보기**: "보기" 버튼을 눌러 발송된 이메일의 원본 HTML을 확인할 수 있습니다.
3. **재발송**:
   - 발송 실패했거나 다시 보내야 할 경우, 해당 이력의 **"재발송"** 버튼을 클릭합니다.
   - 재발송된 메일은 제목 앞에 `[재발송]` 태그가 붙습니다.

## 6. 트러블슈팅

### start.bat 실행 시 시간 지연 문제

**문제점**: `start.bat` 실행 시 서버 시작까지 불필요하게 긴 시간이 소요됨

**원인**:

- `start.bat` 파일에서 매번 `pip install matplotlib pandas openpyxl` 명령을 실행하도록 설정되어 있음
- 이미 설치된 패키지라도 재설치 여부를 확인하는 과정에서 시간 소요
- 특히 `matplotlib`는 의존성이 많아 설치/검증 시간이 길어질 수 있음

**관련 프로그램**:

- **pip** (Python Package Installer): Python 패키지 관리 도구
- **matplotlib** (v3.x): 데이터 시각화 라이브러리 (약 15-30초 소요)
- **pandas** (v2.x): 데이터 분석 라이브러리 (약 10-20초 소요)
- **openpyxl** (v3.x): 엑셀 파일 처리 라이브러리 (약 5-10초 소요)

**해결 방안**:

1. **사전 설치 권장**: `start.bat` 실행 전 터미널에서 한 번만 설치
   ```bash
   venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. **start.bat 수정**: 패키지 설치 명령 제거 또는 설치 여부 확인 후 실행하도록 변경
3. **가상환경 유지**: venv 폴더를 삭제하지 않고 유지하여 재설치 방지

**작업 시간 영향**:

- 초기 설치 시: 약 1-2분 소요
- 매 실행마다 재설치 시: 불필요한 30초-1분 지연 발생

### 이메일 발송 실패

- `.env` 파일의 SMTP 설정이 올바른지 확인하세요.
- 사내 네트워크 보안 정책으로 인해 SMTP 포트가 차단되었는지 확인하세요.
- `server_error.log` 파일에서 상세 에러 로그를 확인할 수 있습니다.

### AI 인사이트 생성 실패

- AWS 자격 증명(AWS Credentials)이 올바르게 설정되었는지 확인하세요.
- `.aws/credentials` 파일 또는 환경 변수를 확인하세요.

### 서버 연결 오류

- 백엔드 서버(`server.py`)가 실행 중인지 확인하세요.
- 프론트엔드에서 백엔드 API 주소(`http://localhost:8001`)가 올바르게 설정되었는지 확인하세요.

# 코브랜드 주간 현황 리포트 생성기 (Co-Brand Weekly Report Generator) 매뉴얼

## 1. 프로젝트 개요

본 프로젝트는 엑셀 형태의 주간 트래픽 데이터를 분석하여 시각화된 대시보드를 제공하고, AI 기반의 인사이트가 포함된 HTML 이메일 리포트를 자동 생성 및 발송하는 시스템입니다.

### 주요 기능

- **엑셀 데이터 분석**: 주간 트래픽 엑셀 파일을 업로드하여 자동 파싱 및 분석
- **AI 인사이트 생성**: AWS Bedrock을 활용하여 데이터 기반의 핵심 요약 자동 생성
- **대시보드 시각화**: 주요 지표(UV, 증감률, 디바이스 점유율 등)를 차트와 테이블로 시각화
- **이메일 리포트 생성 및 발송**: 분석된 데이터를 바탕으로 HTML 이메일 리포트 생성 및 SMTP 발송
- **수신자 관리**: 이메일 수신자 목록 관리 (추가/삭제/동기화)
- **발송 이력 및 재발송**: 과거 발송된 이메일 이력 조회 및 재발송 기능
- **프롬프트 관리**: AI 요약 생성에 사용되는 프롬프트를 직접 수정 및 관리

## 2. 시스템 요구사항 및 설치

### 필수 요구사항

- **Python**: 3.8 이상
- **Node.js**: 16.0 이상
- **AWS 계정**: Bedrock 접근 권한 필요 (AI 기능 사용 시)
- **SMTP 서버 정보**: 이메일 발송을 위한 SMTP 계정

### 설치 방법

#### 1. 백엔드 (Python) 설정

프로젝트 루트 디렉토리에서 실행합니다.

```bash
# 가상환경 생성 (선택사항)
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 의존성 패키지 설치
pip install -r requirements.txt
```

#### 2. 프론트엔드 (React) 설정

`dashboard` 디렉토리로 이동하여 실행합니다.

```bash
cd dashboard
npm install
```

#### 3. 환경 변수 설정 (.env)

프로젝트 루트에 `.env` 파일을 생성하고 다음 정보를 입력합니다. (예시: `.env.example` 참조)

```ini
# AWS Bedrock 설정 (AI 인사이트용)
AWS_REGION=us-west-2
MODEL_ID=anthropic.claude-sonnet-4-6
ANTHROPIC_VERSION=bedrock-2023-05-31

# 이메일 SMTP 설정
SMTP_SERVER=smtp.example.com
SMTP_PORT=587
EMAIL_SENDER=your-email@example.com
EMAIL_PASSWORD=your-password
EMAIL_RECIPIENTS=receiver1@example.com,receiver2@example.com
```

## 3. 실행 가이드

### 간편 실행 (Windows)

프로젝트 루트 디렉토리의 배치 파일을 사용하여 간편하게 서버를 실행하고 종료할 수 있습니다.

#### 1. 서버 실행 (`start.bat`)

`start.bat` 파일을 더블 클릭하여 실행합니다.

- 자동으로 가상환경을 활성화하고 필요한 라이브러리를 설치합니다.
- 백엔드(8001 포트)와 프론트엔드(5173 포트) 서버를 순차적으로 실행합니다.
- 실행이 완료되면 자동으로 크롬 브라우저가 열립니다.

#### 2. 서버 종료 (`stop.bat`)

`stop.bat` 파일을 더블 클릭하여 실행합니다.

- 실행 중인 Python 및 Node.js 프로세스를 안전하게 종료합니다.
- 열려 있는 서버 터미널 창들을 닫습니다.

### 수동 실행 (개발자용)

#### 1. 백엔드 서버 실행

```bash
# 프로젝트 루트에서
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python server.py
```

- 서버는 `http://localhost:8001`에서 실행됩니다.

#### 2. 프론트엔드 개발 서버 실행

```bash
# dashboard 폴더에서
cd dashboard
npm install
npm run dev
```

- 브라우저에서 `http://localhost:5173`으로 접속합니다.

## 4. 사용 방법

### 1. 데이터 업로드 및 분석

1. 대시보드 메인 화면에서 **"엑셀 파일 선택"** 버튼을 클릭하여 주간 데이터 엑셀 파일을 업로드합니다.
2. **"분석 시작"** 버튼을 클릭하면 데이터 파싱과 AI 요약 생성이 진행됩니다.
3. 분석이 완료되면 화면에 대시보드가 표시됩니다.

### 2. 리포트 편집 및 확인

- **AI 인사이트**: 생성된 인사이트 내용을 직접 수정할 수 있습니다.
- **요약 재생성**: AI가 생성한 요약이 마음에 들지 않을 경우, **"요약 재생성"** 버튼을 클릭하여 새로운 요약을 생성할 수 있습니다.
- **메일 본문 추가**: "메일 본문 추가" 체크박스를 켜고, Quill 에디터를 통해 이메일 상단에 들어갈 인사말이나 공지사항을 작성할 수 있습니다.

### 3. 이메일 발송

1. 우측 상단의 **"수신자 관리"** 버튼을 눌러 수신자 목록을 확인하고 수정합니다.
2. **"이메일 발송"** 버튼을 클릭하면 현재 대시보드 내용으로 HTML 리포트가 생성되어 발송됩니다.

### 4. 발송 이력 및 재발송

- 대시보드 하단의 **"발송 이력"** 섹션에서 과거 발송된 리포트 목록을 확인할 수 있습니다.
- **"재발송"** 버튼을 클릭하면 해당 시점의 리포트를 다시 발송할 수 있습니다. (제목에 `[재발송]` 태그 추가됨)

### 5. 프롬프트 관리

1. 대시보드 상단의 **"프롬프트 관리"** 버튼을 클릭합니다.
2. 팝업창에서 현재 적용된 AI 프롬프트 내용을 확인할 수 있습니다.
3. 내용을 수정한 후 **"저장"** 버튼을 누르면 즉시 반영됩니다.
4. **"기본값 복원"** 버튼을 누르면 초기 설정된 프롬프트로 되돌릴 수 있습니다.

## 6. 트러블슈팅

### start.bat 실행 시 시간 지연 문제

**문제점**: `start.bat` 실행 시 서버 시작까지 불필요하게 긴 시간이 소요됨

**원인**:

- `start.bat` 파일에서 매번 `pip install matplotlib pandas openpyxl` 명령을 실행하도록 설정되어 있음
- 이미 설치된 패키지라도 재설치 여부를 확인하는 과정에서 시간 소요
- 특히 `matplotlib`는 의존성이 많아 설치/검증 시간이 길어질 수 있음

**관련 프로그램**:

- **pip** (Python Package Installer): Python 패키지 관리 도구
- **matplotlib** (v3.x): 데이터 시각화 라이브러리 (약 15-30초 소요)
- **pandas** (v2.x): 데이터 분석 라이브러리 (약 10-20초 소요)
- **openpyxl** (v3.x): 엑셀 파일 처리 라이브러리 (약 5-10초 소요)

**해결 방안**:

1. **사전 설치 권장**: `start.bat` 실행 전 터미널에서 한 번만 설치
   ```bash
   venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. **start.bat 수정**: 패키지 설치 명령 제거 또는 설치 여부 확인 후 실행하도록 변경
3. **가상환경 유지**: venv 폴더를 삭제하지 않고 유지하여 재설치 방지

**작업 시간 영향**:

- 초기 설치 시: 약 1-2분 소요
- 매 실행마다 재설치 시: 불필요한 30초-1분 지연 발생

### 이메일 발송 실패

- `.env` 파일의 SMTP 설정이 올바른지 확인하세요.
- 사내 네트워크 보안 정책으로 인해 SMTP 포트가 차단되었는지 확인하세요.
- `server_error.log` 파일에서 상세 에러 로그를 확인할 수 있습니다.

#### "535 Authentication unsuccessful, the user credentials were incorrect" (Microsoft 365 / Outlook)

Microsoft 365(또는 @hanatour.com 등 조직 계정)에서 위 오류가 나면 **인증 방식** 문제일 가능성이 큽니다.

1. **앱 비밀번호 사용 (MFA 사용 시)**  
   - 해당 계정에 **다단계 인증(MFA)**이 켜져 있으면 일반 비밀번호로는 SMTP 로그인이 되지 않습니다.  
   - [Microsoft 계정 보안](https://account.microsoft.com/security) → **추가 보안 인증** → **앱 비밀번호**에서 새 앱 비밀번호를 생성한 뒤, `.env`의 `EMAIL_PASSWORD`에 **이 앱 비밀번호**를 넣어 사용하세요.

2. **SMTP 인증 허용 (관리자)**  
   - 관리자(또는 IT)에게 해당 메일함에 대해 **Authenticated SMTP**(SMTP 인증) 사용 허용을 요청하세요.  
   - Microsoft 365 관리 센터 → 사용자 → 해당 사용자 → 메일 → **인증된 SMTP** 사용 설정.

3. **서버 주소**  
   - 조직 계정(@hanatour.com)은 `smtp.office365.com`, 포트 `587`을 사용합니다.  
   - 코드에서 @hanatour.com인 경우 자동으로 이 설정을 사용합니다.  
   - `.env`에 `SMTP_SERVER`를 따로 넣었다면 `smtp.office365.com`인지 확인하세요.

### AI 인사이트 생성 실패

- AWS 자격 증명(AWS Credentials)이 올바르게 설정되었는지 확인하세요.
- `.aws/credentials` 파일 또는 환경 변수를 확인하세요.

### 서버 연결 오류

- 백엔드 서버(`server.py`)가 실행 중인지 확인하세요.
- 프론트엔드에서 백엔드 API 주소(`http://localhost:8001`)가 올바르게 설정되었는지 확인하세요.

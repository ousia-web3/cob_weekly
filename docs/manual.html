코브랜드 주간 현황 리포트 생성기

사용자 매뉴얼 v1.2 (2026.01.19)

본 시스템은 주간 트래픽 엑셀 데이터를 분석하여 시각화된 대시보드를 제공하고, AI 기반의 인사이트가 포함된 이메일 리포트를 자동으로 생성 및 발송하는 도구입니다.

🖥️ 접속 및 실행 가이드

1. 서버 실행 (관리자)

프로젝트 폴더 내의 start.bat 파일을 실행하면 서버와 브라우저가 자동으로 열립니다.

2. 접속 주소

관리자 (서버 실행 PC)

http://localhost:5173

📢 내부 임직원 (사내망 접속)

사내망에 연결된 다른 PC나 모바일 기기에서 아래 주소로 접속하세요.

http://192.168.82.105:5173

※ 접속이 안 될 경우, 관리자 PC의 방화벽 설정(8001, 5173 포트)을 확인해주세요.

📊 엑셀 업로드 및 분석

  1. 기간 설정

    화면 상단의 드롭다운 메뉴에서 보고서의 연도, 월, 주차를 선택합니다. 날짜 범위는 자동으로 계산됩니다.

  2. 파일 업로드

    화면 중앙의 "엑셀 파일을 이곳에 드래그..." 영역에 파일을 끌어다 놓거나 클릭하여 선택합니다.

  3. 분석 시작

    파일이 선택되면 "분석 시작" 버튼을 클릭합니다. 진행률 바가 100%가 될 때까지 잠시 기다려주세요.

🖥️ 대시보드 미리보기 UI 구성

분석이 완료되면 생성되는 대시보드 화면의 주요 구성 요소입니다.

1. 상단 핵심 지표 (KPI Cards)
  • 전체 UV & 증감률: 금주 전체 방문자 수와 전주 대비 증감률을 표시합니다.
  • 모바일 비중: 전체 트래픽 중 모바일 기기 접속 비율입니다.
  • Best & Worst: 전주 대비 가장 많이 성장한 카테고리와 가장 많이 하락한 카테고리를 보여줍니다.
2. 차트 시각화
  • 주간 추이 (Area Chart): 최근 주간 트래픽 변화를 그래프로 시각화합니다.
  • 디바이스/채널 점유율 (Pie Chart): PC/Mobile 비율 및 유입 채널별 비중을 파이 차트로 제공합니다.
3. 상세 데이터 테이블
  • Co-Brand Top 20: UV 기준 상위 20개 대리점/채널 리스트입니다. 신규진입 표시
  • 카테고리별 상세 실적: 패키지, 항공, 호텔 등 카테고리별 상세 수치입니다.
    ※ "상세보기/접기" 버튼을 통해 세부 항목을 펼치거나 숨길 수 있습니다.
  • 채널 유형별 Top 10: 브랜드몰, 제휴사, 공식인증센터 각각의 Top 10 순위표입니다.

🤖 AI 핵심 요약 검수

분석이 완료되면 대시보드 상단에 AI가 생성한 "핵심 요약(Executive Summary)"이 표시됩니다.

  • 내용 확인: AI가 작성한 4가지 주요 인사이트를 꼼꼼히 확인합니다.
  • 직접 수정: 각 요약 항목의 텍스트 박스를 클릭하여 내용을 직접 수정할 수 있습니다. 오타나 강조하고 싶은 내용을 자유롭게 편집하세요.

✍️ 메일 본문 작성 (에디터)

이메일 상단에 들어갈 인사말이나 공지사항을 작성하는 기능입니다.

  1. 대시보드 우측 상단의 "메일 본문 추가" 체크박스를 클릭하여 에디터를 활성화합니다.
  2. 나타나는 에디터 창에 내용을 작성합니다. (예: "안녕하세요, 금주 주간 보고 드립니다.")
  3. 텍스트를 드래그하여 굵게, 색상 변경 등의 서식을 적용할 수 있습니다.

👥 수신자 관리

이메일을 받을 대상자를 관리합니다. 우측 상단의 "수신자 관리" 버튼을 클릭하세요.

  • 추가: 이메일 주소를 입력하고 "추가" 버튼 클릭
  • 삭제: 목록에서 삭제할 이메일 옆의 휴지통 아이콘 클릭
  • .env 동기화: 현재 목록을 환경 설정 파일에 영구 저장 (서버 재시작 후에도 유지됨)

발송 및 이력 관리

🚀 이메일 발송

모든 확인이 끝나면 우측 상단의 "이메일 발송" 버튼을 클릭하세요. 잠시 후 "발송 완료" 알림이 뜹니다.

발송 이력 확인

화면 최하단의 "발송 이력" 섹션에서 과거 내역을 확인할 수 있습니다.

  • 상태 확인: 성공/실패 여부가 표시됩니다.
  • 미리보기: "보기" 버튼으로 발송된 원본 HTML을 확인할 수 있습니다.
  • 재발송: "재발송" 버튼을 누르면 해당 시점의 리포트를 다시 발송합니다. (제목에 [재발송] 태그 자동 추가)

# 메일 재발송 기능 추가 작업 내역

## 1. 개요

이메일 발송 이력을 조회하고, 발송된 이메일을 다시 보낼 수 있는 기능을 추가했습니다.

## 2. 변경 사항

### 백엔드 (`server.py`)

- **API 추가**:
  - `GET /api/email/history`: `data/email` 폴더에 저장된 이메일 HTML 파일 목록을 반환합니다.
  - `POST /api/email/resend/{filename}`: 특정 HTML 파일을 읽어 이메일을 재발송합니다. 제목 앞에 `[재발송]` 태그가 자동으로 추가됩니다.

### 프론트엔드 (`dashboard/src`)

- **컴포넌트 추가**: `components/EmailHistory.jsx`
  - 발송된 이메일 목록을 테이블 형태로 표시합니다.
  - "재발송" 버튼을 클릭하면 해당 이메일을 다시 발송합니다.
- **App.jsx 수정**:
  - `EmailHistory` 컴포넌트를 메인 화면 하단(미리보기 위)에 추가했습니다.

## 3. 사용 방법

1. **서버 재시작**: 변경된 `server.py`를 적용하기 위해 백엔드 서버를 재시작해주세요.
   ```bash
   # 기존 서버 중지 후
   python server.py
   ```
2. **대시보드 확인**:
   - 대시보드 하단에 "발송 이력" 섹션이 새로 생겼습니다.
   - 이전에 발송된 이메일 목록이 표시됩니다. (파일이 `data/email` 폴더에 있어야 함)
   - "재발송" 버튼을 누르면 확인 팝업 후 메일이 발송됩니다.

## 4. 주의 사항

- 재발송 시 수신자는 현재 설정된 수신자 목록(또는 `.env`)을 따르는 것이 아니라, `email_service.send_email` 로직에 따라 활성 수신자에게 전송됩니다.
- 발송 이력은 `data/email` 폴더의 파일을 기준으로 하므로, 해당 폴더의 파일을 삭제하면 이력에서도 사라집니다.
